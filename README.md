# Client Concepts

Live site: https://nox-do.github.io/client-concepts/

A small collection of static concept pages, pitches, and lightweight product prototypes.

## Concepts

- Wartezimmer - https://nox-do.github.io/wartezimmer/ — lokale Praxisorganisation; Source-available. Quellcode: https://github.com/nox-do/wartezimmer. Downloads: https://github.com/nox-do/wartezimmer/releases/tag/v6.1.7
- Klartext fuer LinkedIn - https://nox-do.github.io/klartext-fuer-linkedin/
- Abyssal Garden - https://nox-do.github.io/abyssal-garden/ — prozedurale Unterwasserwelt mit WebGPU und Web Audio in einer offline nutzbaren HTML-Datei. Erweiterter Fork des Originals von Maksymilian Dendura (Noniv), MIT. Quellcode: https://github.com/nox-do/abyssal-garden.
- Staticseal - https://nox-do.github.io/staticseal/
- Daniel Deuter — https://deuter.org/ — persönliche Website; ausschließlich die öffentliche Website verlinken, nicht das private Repository.

- BB Pilot — https://bbpilot.de/de — öffentliche Website und App, kein Repository-Link.
- SokoBoulder — https://github.com/nox-do/sokoboulder — native macOS-Spiele; Downloads über Releases.
- Gedankenpalast — frühes Experiment mit einer statischen Luanti-Bibliotheksprobe; noch keine öffentliche Demo und kein Repository-Link.

## Gestaltung und Bilder

Dunkler Hintergrund, orange Akzente, dünne Linien und Projektkacheln. Statische
HTML-Seite ohne Build-Schritt. Lokale Vorschau: `python3 -m http.server 8765`.

Die Bilder liegen unter `assets/`: Wartezimmer-Raumpanel aus den Website-Assets,
Klartext-Produktansicht, Staticseal-Produktansicht und das bereits für deuter.org
verwendete Porträt. Das Porträt wurde anhand echter Fotos mit ImageGen überarbeitet.
Abyssal Garden ist eine Browseraufnahme des öffentlichen Forks; Original von
Maksymilian Dendura (Noniv), MIT. Bildausschnitte werden ausschließlich per CSS gesetzt.

Zusätzliche Motive: BB-Pilot-Dashboard aus der bereits öffentlichen Produktansicht,
SokoBoulder aus dem dokumentierten Spiel-Screenshot. Gedankenpalast verwendet eine
lokal erstellte SVG-Konzeptskizze; sie ist ausdrücklich keine Produktaufnahme.
